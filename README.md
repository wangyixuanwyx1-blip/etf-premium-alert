## 二、溢价率怎么算

```
溢价率 = (场内价格 - 基金净值) / 基金净值 × 100%
```

- **场内价格**：A 股盘中实时成交价（腾讯行情接口字段[3]，每 5 分钟取一次）
- **基金净值**：QDII 基金最新公布的单位净值（腾讯行情接口字段[78]，与天天基金 dwjz、同花顺溢价率口径一致，盘中固定）
- QDII-ETF 的净值在 A 股交易时段内**固定不变**（底层美股/日股/韩股已收盘），所以盘中算出的溢价率是**真实有效**的

> ⚠️ **数据源说明（重要）**：不要用东方财富 trends2 接口的 `preSettlement` 字段当净值——它对 ETF 返回的是**昨日场内收盘价**而非基金净值，用它算"溢价率"实际得到的是"当日涨跌幅"，会完全失真（例如 513520 日经ETF 会被错算成 -1.88% 而真实为 +4.2%）。腾讯 [78] 字段已经与同花顺交叉验证一致（513520 +4.19% vs 4.2%；513310 +11.75% vs 11.93%）。

**溢价率含义**：>0 说明场内买贵了（溢价），<0 说明场内便宜了（折价）。买入信号是**低溢价/折价**（少付溢价），卖出信号是**高溢价**（溢价回吐）。

## 三、部署步骤（约 15 分钟）

### 第 1 步：注册 GitHub 账号
打开 https://github.com 注册（已有账号跳过）。免费。

### 第 2 步：获取 PushPlus Token
1. 微信扫码关注公众号「PushPlus 推送加」（https://www.pushplus.plus/）
2. 登录 PushPlus 官网，点「一对一推送」，复制你的 **token**（一串字母数字）

### 第 3 步：创建仓库并上传代码
1. GitHub 右上角 **+ → New repository**，命名如 `etf-premium-alert`
2. **必须选 Public（公开）**——公开仓库 GitHub Actions 无限时长，且个人投资阈值不算隐私
3. 把本目录下的文件上传（`monitor.py`、`.github/workflows/monitor.yml`、`README.md`），可以用网页上传，或：
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/etf-premium-alert.git
   git push -u origin main
   ```

### 第 4 步：配置 PushPlus Token（GitHub Secrets）
1. 仓库页面 → **Settings → Secrets and variables → Actions → New repository secret**
2. Name 填：`PUSHPLUS_TOKEN`
3. Secret 填：第 2 步复制的 token

### 第 5 步：手动验证
1. 仓库页面 → **Actions → ETF Premium Monitor → Run workflow**（手动触发一次）
2. 几分钟后：微信收到「🛰️ 监控已启动」快照 = 成功
3. 点进 Actions 运行记录，绿色对勾 = 正常；红色 = 点开看日志排查

### 第 6 步：自动运行
工作流已内置定时任务：**周一至周五 09:30-15:00 每 5 分钟**跑一次（节假日自动跳过，脚本会检测行情日期）。

## 六、常见问题

**Q：GitHub Actions 会按时跑吗？**
调度可能有 1-5 分钟延迟，属正常现象。对溢价提醒来说足够及时。注意：**公开仓库免费无时长限制；私有仓库每月 2000 分钟**（本方案约 300 分钟/月）。

**Q：仓库 60 天没活动会怎样？**
GitHub 会暂停该仓库的定时任务。解决办法：偶尔手动 Run workflow 一次，或随便提交个文件。届时收到提醒变少，检查一下即可。

**Q：节假日会乱提醒吗？**
不会。脚本会校验腾讯行情日期是否为今天，非交易日直接跳过。

**Q：为什么有时净值是前一天的？**
QDII 基金净值每日上午公布（反映隔夜海外收盘），盘中固定不变，这正是计算真实溢价率所需的基准。若个别基金当天净值公布较晚，则沿用前一日净值，溢价率偏差约等于隔夜涨跌幅（通常 <2%）。

**Q：PushPlus 免费版够用吗？**
免费版 200 条/天。脚本做了**状态去重 + 30 分钟冷却**：同一标的只在区间切换时提醒一次，通常一天 <10 条。

**Q：想用企业微信机器人替代 PushPlus？**
可以。企业微信群添加机器人获取 webhook，把 `pushplus_send` 换成 POST webhook 即可（内容格式改 text/markdown）。

**Q：只想本地跑，不用 GitHub？**
Mac 上 `python3 monitor.py` + crontab 即可，但需要电脑在交易时段开机。GitHub Actions 是推荐方式（云端跑，手机收提醒）。
